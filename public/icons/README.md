# Component artwork

Redis, PostgreSQL (also used for read replicas), Apache Kafka, and RabbitMQ logos
are vendored without modification from Devicon v2.17.0:

- https://github.com/devicons/devicon/blob/v2.17.0/icons/redis/redis-original.svg
- https://github.com/devicons/devicon/blob/v2.17.0/icons/postgresql/postgresql-original.svg
- https://github.com/devicons/devicon/blob/v2.17.0/icons/apachekafka/apachekafka-original.svg
- https://github.com/devicons/devicon/blob/v2.17.0/icons/rabbitmq/rabbitmq-original.svg

Devicon's MIT license is included in `devicon-LICENSE.txt`. Product names and marks
belong to their respective owners; their appearance identifies the technology.
Kafka is displayed in a light color using CSS for legibility on the dark canvas.
Bob and the vendor-neutral infrastructure symbols are original SVG artwork in
`src/components/bob/BobAvatar.tsx` and `src/components/ComponentIcon.tsx`.

All assets are served locally. No image CDN or account is required at runtime.
